# link-in-bio

Personal link page for @lifeoflucalisti.

- **Edit content:** `site/config.js` (name, bio, links, races)
- **Edit design:** `site/index.html`
- **Preview:** VS Code → right-click `site/index.html` → *Open with Live Server*
- **Check config:** `node scripts/check-config.js`
- **Deploy:** push to `main`. GitHub Actions validates `config.js`, then deploys `site/` to GitHub Pages.
